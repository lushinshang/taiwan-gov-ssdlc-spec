## 為什麼做

許多軟體開發團隊與初階工程師在面對政府標案或資安檢測時，常因官方規範與法規文字晦澀繁複而不知所措，容易落入「開發完才丟給資安掃描、報告一出幾百個紅字不知如何修改」的痛苦循環。
本需求旨在 `simple/` 目錄下建立一個全新、極度白話且直觀的 `simple/index.html`，專門作為「新手開發團隊安全開發實戰指引」。透過生動比喻、圖解視覺化（利用 `codex exec` 生成豐富的繁體中文資訊圖，數量不限）、程式碼前後對照及檢查表，協助開發團隊建立「一次就寫對、準時下班」的安全開發心智模型。

## 要改什麼

- 建立 `simple/images/` 目錄，用於存放各關鍵章節之資訊圖檔。
- 平行調度多位專責 Subagents，並依任務特性指派最適模型（`pro` 負責深層文字解構與邏輯把關，`flash` 負責調度指令與批次生圖）：
  1. 撰寫第 0-1 章：觀念翻轉與專有名詞白話字典（SAST、DAST、SCA、SBOM、滲透測試生活比喻）。
  2. 撰寫第 2 章：寫 Code 防禦實戰（輸入驗證、防 SQLi/XSS/SSRF、密鑰治理、套件體檢與 Safe vs Vulnerable 程式碼對照）。
  3. 撰寫第 3 章：測試環境與資料安全（去識別化四步法流水線、邊界與異常測試）。
  4. 撰寫第 4-5 章：驗收三大魔王通關（源碼檢測修補、黑箱準備、滲透測試應對）與上線前 5 分鐘自我檢核表。
- 呼叫 `codex exec` 生成多張高質感 16:9 / 9:16 直式資訊圖表，直觀圖解各核心觀念。
- 整合輸出 publish-ready 的 `simple/index.html`，具備暖白底色、台灣繁體中文、直式 Mermaid 流程圖，並針對手機 360–400px 直屏無橫向捲軸優化。
