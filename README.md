本專案依據《資通安全管理法》第 9 條及施行細則第 7 條、數位發展部《資通系統防護基準》（附表十）及行政院公共工程委員會最新《資訊服務採購契約範本》，專門針對受託廠商於「程式開發實作」、「功能與系統測試」至「資訊安全技術檢測（SAST / DAST / 滲透測試）」建立之**全流程履約作業標準與工程師落地指南**。

## 💡 為什麼需要這套規範？

許多軟體團隊在承攬政府標案時，常面臨以下痛點：
1. **法條與規範晦澀繁雜**：不知道什麼時候該做源碼檢測、什麼時候該做滲透測試，常誤把機關該填的「附表九（分級原則）」當成廠商自己的作業。
2. **驗收前夕幾百個紅字退件**：等到上線前一週才跑掃描，報告一出滿江紅，修補不及導致驗收延宕、會計依契約無法撥款，甚至面臨每日逾期罰款。
3. **缺少工程落地範例**：一般資安宣導多為抽象原則，缺少具體的「危險寫法 ❌ vs 安全寫法 ✅」代碼對照、SBOM 產出指令與去識別化脫敏流程。

本專案將抽象的官方規範與工程師日常開發（需求 ➔ 開發 ➔ 測試 ➔ 驗收）進行 **1:1 精確映射**，讓團隊能夠在開發階段順手把關，一次通過驗收！

| :--- | :--- | :--- |
| **導讀：術語與心態** | **🌱 導讀：名詞白話字典與觀念翻轉** | 提早把關（Shift Left）；SAST（查食譜）、DAST（踹門）、SCA/SBOM（食品標籤）、滲透測試（白帽攻堅）。 |
| **零、廠商遵循總則與法遵拘束力** | **⚖️ 零、合約與請款真相** | 解構工程會契約第 8/15 條與資安法第 9 條；資安報告是法定驗收條件，沒過會計不能撥款。 |
| **壹、官方依據文件下載庫** | **📚 壹、這堆 PDF 到底誰該看？** | 附表九由**機關自己評**；廠商依核定等級照**附表十**落實檢測；提供全數本地原檔下載。 |
| **貳、專案執行計畫與管理規範** | **🗓️ 貳、Sprint 計畫與 1 小時通報** | WBS 拆解資安工作包；RACI 權責分工（嚴禁自己寫自己審）；資安事故「1 小時緊急通報 SOP」。 |
| **參、安全程式開發階段實作規範** | **🛡️ 參、Coding 階段防禦四道門禁** | OWASP Top 10:2025 對照；SQLi/XSS/SSRF 安全代碼對照；用 `syft` 一行指令產出 SBOM，`grype` 查弱點；禁用大陸廠牌切結。 |
| **肆、功能與系統測試階段規範** | **🧪 肆、Testing 階段脫敏與硬碟抹除** | 嚴禁 dump 正式機真實 DB；Faker/Masking/Hashing 脫敏四大招；負向測試；退租硬碟 NIST SP 800-88 安全抹除。 |
| **伍、資訊安全技術檢測作業規範** | **👾 伍、驗收前三大考通關秘笈** | SAST 白箱（High/Critical 100% 歸零、誤判說明公式）；DAST 黑箱（WAF 白名單放行、Swagger 準備）；滲透測試（防業務越權、自測證明）。 |

## 🎨 特色與體驗優化

1. **AI 視覺資訊圖表（自適應響應）**：
   - 包含「提早把關成本對比圖」、「防禦四道門禁」、「脫敏流水線」與「三大檢測魔王全景圖」。
   - 採用 `<picture>` 標籤，桌機呈現 16:9 橫向資訊圖，手機螢幕無縫切換為 9:16 直式圖表。
2. **極致行動端體驗（Mobile-First）**：
   - 通過 Playwright 自動化實測（360px、375px、414px 直屏），**全域無橫向滾動條**，支援單手向下流暢閱讀。
   - 所有流程圖均採用 Mermaid `flowchart TD` 直式佈局。
3. **雙模型嚴謹審查驗證**：
   - 經 **Claude 3.7 Sonnet** 與 **Codex CLI (`gpt-6-sol`)** 交叉深度技術與法規審查，確保法源依據、程式碼範例與實戰可行性均站得住腳。

## 📜 依據法源與技術規範

- **法規依據**：
  - 《資通安全管理法》第 9 條及施行細則第 7 條（受託者選任、監督與安全性檢測證明）
  - 《資通安全責任等級分級辦法》附表九「資通系統防護需求分級原則」
  - 《資通安全責任等級分級辦法》附表十「資通系統防護基準」
  - 行政院公共工程委員會《資訊服務採購契約範本》
- **技術標準**：
  - OWASP Top 10:2025 應用程式安全風險
  - 國家資通安全研究院 (NICS)《Web 應用程式安全參考指引》v3.2
  - NIST SP 800-88 Rev. 2 媒體清除指引 (Guidelines for Media Sanitization)
  - CycloneDX / SPDX 軟體物料清單 (SBOM) 規範
